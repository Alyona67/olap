# ETL-процесс загрузки данных

Скрипт `load.py` выполняет загрузку сырья в базу данных DuckDB (`retail.duckdb`) с проверкой качества.

Стратегия повтора: перед каждой загрузкой скрипт удаляет все старые таблицы (`DROP TABLE IF EXISTS`), поэтому повторный запуск полностью пересоздает витрину и не приводит к дублированию данных.
