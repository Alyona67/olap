# Ограничения проекта

## 1. Анализ реальной географии продаж

Исключаем: анализ реального распределения продаж продуктовой сети по конкретным магазинам и географическим регионам.

Причина: данные о магазинах, их расположении и товарах сформированы синтетически для учебной модели. Транзакции относятся к магазинам искусственно.

Последствия: витрина позволяет выполнять учебный анализ продаж в разрезе магазинов, городов и регионов, однако полученные результаты нельзя интерпретировать как реальные показатели конкретных магазинов.



## 2. Временные интервалы внутри дня

Исключаем: анализ покупок по часам и минутам, определение «часов пик».

Причина: в данных есть только date_id (день), без времени суток.

Последствия: витрина покажет продажи по дням и месяцам, но не по часам. Для анализа «в какое время дня магазин загружен» потребовались бы данные с точностью до минуты.



## 3. Анализ способов оплаты

Исключаем: анализ оплаты наличными, картой, бонусами, рассрочкой.

Причина: в fact_sales нет поля о способе оплаты.

Последствия: витрина не покажет, как клиенты предпочитают платить. Для такого анализа потребовалось бы поле payment_method.
